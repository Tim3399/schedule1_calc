- Upstream: <https://github.com/jpt/barlow> (named in the package licence; the package repository is <https://github.com/fontsource/font-files>)
- Downloaded: 2026-11-15 with `npm pack @fontsource/barlow`; the files are copied unchanged.
- Files: `barlow-latin-700-normal.woff2`, `barlow-latin-800-normal.woff2`
