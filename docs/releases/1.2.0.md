# 1.2.0 – Berechnung im Browser

Die Website führt beide Suchmodi auf dem Gerät des Besuchers in einem Web Worker aus. Der Server liefert Oberfläche, Skripte und Spieldaten über `GET /search-data`. Es gibt keinen Rückfall auf eine Serverberechnung. Eine laufende Suche lässt sich abbrechen und anschließend neu starten.

Die exakte Suche liefert nur bei vollständig bewiesenem Optimum Gewinner. Bei überschrittenem Zeit-, Arbeits- oder Größenlimit fehlen Gewinner vollständig. Der Schnellmodus kennzeichnet seine Ergebnisse weiterhin als Näherung. Die Browser-Portierung wurde mit vollständigen Python-Gewinnern verglichen, einschließlich fünf Zutaten für alle acht Produkte und sechs Zutaten für OG Kush.

## Änderung für API-Clients

Die Server-Rechen-API bleibt im Programm erhalten, ist aber standardmäßig deaktiviert: `POST /` und `POST /get_best_mix` liefern ohne konfigurierten Zugang HTTP 404, bevor eine Berechnung beginnt.

Nur für eine bewusst freigegebene private Nutzung kann der Betreiber `SCHEDULE1_API_TOKEN` setzen. Jeder Aufruf benötigt dann `Authorization: Bearer <token>`; fehlende oder falsche Berechtigung liefert HTTP 401. Das Token gehört ausschließlich auf den Server und in berechtigte API-Clients, niemals in Browser-Code oder öffentliche Konfiguration. Bisherige anonyme API-Clients müssen entsprechend umgestellt werden. Die Minor-Version ist eine ausdrückliche Nutzerentscheidung trotz dieser Zugangsbeschränkung.

## Öffentlicher Betrieb

- Das veröffentlichte Container-Image unterstützt Linux/amd64, lauscht auf Port 8080 und läuft mit UID/GID 10001.
- Für die öffentliche Website `SCHEDULE1_API_TOKEN` nicht setzen. Es werden keine Rechenkapazität und kein Token für Besucher benötigt.
- Keine Datenbank und kein persistentes Datenverzeichnis sind für den Rechner erforderlich.
- Reverse Proxy und CSP müssen gleich-originäre Modell-GETs sowie das Laden der drei Suchskripte und des Web Workers erlauben.
- Zum Deployment den unveränderlichen Image-Digest aus dem Publication Receipt verwenden. Browser-Funktionsprüfung und die Ablehnung beider anonymen POST-Pfade gehören zur Abnahme.

Die Veröffentlichung erzeugt Release-Artefakte. Das Aufsetzen des laufenden Dienstes erfolgt separat über die Infrastrukturverwaltung.
